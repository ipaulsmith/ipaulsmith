Software should be understandable — by people and by the agents working beside them.

I build small, inspectable tools and reproducible experiments for AI-assisted software development.

### Current work

- [**check-docs**](https://github.com/ipaulsmith/check-docs) — a shell pre-commit check that catches stale paths and deleted names in `CLAUDE.md`, `AGENTS.md`, and imported instruction files. No model call, package, or service.

### Experiments and notes
