## Projects and experiments

- [check-docs](https://github.com/ipaulsmith/check-docs): A shell pre-commit hook that checks paths in `CLAUDE.md`, `AGENTS.md`, and files they import. It also checks for deleted names you list in `deleted-names.txt`.

- [Jev × NASA Kepler](https://gist.github.com/ipaulsmith/e5c3ae3a492a455435d5bfc161404312): A retrospective test of Jev against NASA Kepler classifications, with the labels hidden during prediction. Includes the requests, baselines, and metrics.

- [Audit a Claude Code skill](https://gist.github.com/ipaulsmith/b617efd955ad6a397e4ae2e5870cbc03): A prompt for checking what a third-party skill would run, install, read, send, or change before installing it. The audit is read-only.
